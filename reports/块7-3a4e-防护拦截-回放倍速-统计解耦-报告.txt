计算口径
- 业务失败率 fail = (warn + error) ÷ 原始事件数；protect 永不进分子：EventLog.vue:1422 附近
- 防护拦截率 protect = protect ÷ 原始事件数，只展示、不参与健康度
- 健康度仍只由 ERROR / 5xx / P99 决定（后端 MetricsSnapshotService.health 未改）

压测（真后端 800 QPS × 25s，bannedUser 70% / sensitiveWord 30%，入站限流开启）
- 原始事件 2,088：信息 1,295 / 防护 571 / 警告 222 / 错误 0
- 业务失败率 10.6%（= 222/2088，不含 571 条防护）
- 防护拦截率 27.3%（= 571/2088）
- 顶部四色条：紫色段实测宽 22.16px、min-width 4px；红色段 0 条故宽 0
- 左侧统计 = 右侧严重度分布（1,295 / 571 / 222 / 0 完全一致）
- 指标页实时态：5xx 0.0%、4xx 83.8%，健康度仍为绿色「健康」，无告警原因
- 指标页回放态：业务失败率 (fail) 11.8%，右侧紫字防护拦截率 (protect) 26.3%，
  图表标题「业务失败率 vs 防护拦截率」，并写明「不计入失败率，也不参与健康度判定」
