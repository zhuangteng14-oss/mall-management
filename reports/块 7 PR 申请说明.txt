二、核心功能
══════════════════════════════════════════════════════════════════

1. 可观测基础设施
   - 三条 SSE 端点（指标 / 订单流 / 事件流）+ EventBroadcaster；
     9 类事件环（Stock / Audit / Notify / Sensitive / Identity / Cache / Lock /
     OrderState / Protection）。
   - 每连接一份帧源、环满记账、异步超时关闸；动态背压与智能聚合。
   - 事件台账 observed_event 建表（Migration ⑲）+ 保留期清理 Job；
     MQ 发布 / 消费与批次跨线程透传（MQ 缺席时上屏仍接通）。

2. 指标页
   - S1 时间栈 + 实体栏；ECharts 主题收成一份（甲/乙版差异面）。
   - 7 项图表、库存水位、P99；P99 剔除 SSE 长连接、无样本留空。

3. 实时日志页
   - 三栏驾驶舱、8 类事件卡片流、自然语言句子、色系分档。
   - 「PROTECT」防护拦截独立成级；日志统计与聚合解耦。
   - traceId 链路抽屉；窗口化渲染 + 分页 / 无限滚动；切页不重置。

4. 状态流转页
   - 五态计数、环图、漏斗进度、状态机、时间线。
   - 高保真分析面：24h 积压趋势、耗时直方图、账龄分桶、健康度、最慢 Top N。
   - 底部明细改服务端分页（真实 COUNT + WHERE status=…），不再拿 1000 行
     样本当全集；状态流转明细 / 超时取消汇总口径同步。

5. 攻击模拟器
   - 八场景真压测、权重编排、异步引擎、开关面板/档位、/attack/stop。
   - 演练记录落库；清场；演示种子。
   - 演练环境复位 / 种子回填：
       · POST /admin/observe/attack/reset（种子 SKU 库存、父商品在架、
         演示商家解冻、秒杀已售复位；真实业务行不动；写审计
         OBSERVE_ATTACK_RESET）；
       · /attack/run 前 autoResetIfNeeded()（尽力而为，失败只记 WARN）；
       · 清场与复位合并，按钮改为「清理并恢复环境」；
       · 前端失败态「一键重置演练商品库存」并自动重跑。

6. 回放
   - 日志 / 指标 / 状态三页共用一根回放时钟，倍速可调。
   - 进度条改原生 range 拖拽（Seek）：
       · @input 不重绘；@change 调用一次 seekReplaySession；
       · 停表 → 清空指标拍/流转/日志 → 二分定位 → 0..idx 全量 apply
         → 状态全量重建（指标窗口整段入队后统一推进，避免同毫秒丢条）；
       · 之前在播则续播，之前暂停则停在新位置；
       · seekToken 防重入，rebuilding 抑制历史粒子动画。
   - 孤儿批次守卫：DrillRecordDao 增加 EventCount 子查询 → HasData；
     下拉置灰「（数据已过期清理）」，空批次不再进入 0/0「已放完」假死。

7. 库存治理
   - CAS 扣减、下单即扣、超时释放条件化；秒杀扣减接线（TD-38）。

8. 稳定性与防护（A 系列）
   - A3 事件幂等键 (TraceId, Seq)；A4 死信上报 + trace 上下文归属；
     A5 掩码回写拦截；A7 SSE 空闲看门狗。
   - 破坏性端点只允许管理员；防护异常统一返 200 + 可识别错误码。
   - 限流 / 熔断 / 分池（第 9 类事件环）；死锁索引 + 重试 + 重试可视化。
   - TraceIdFilter、logback 轮转、慢 SQL 告警。

9. 演示数据源
   - 「模拟日常」保留；日志 / 指标 / 状态三页都保留「数据源」切换入口
     （真实 / 模拟日常），api/demo-stream.js 公开接口未改。
