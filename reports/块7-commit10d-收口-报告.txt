【怎么读这份清单】
每节一张三列表：**操作步骤 → 期望看到 → 判据（怎么算过）**。
判据分两档：
  · 〔可复核〕= 有命令行 / DB 查询可直接对出数（给出 SQL 或命令）
  · 〔当场看〕= 只能眼看（把「什么样子算对、什么样子算错」写死）
颜色只能用来看「有没有明显不对」，判据一律落在**数**上。

⚠️ 【profile 必须分清 —— 这是本清单最容易验错的地方】
  · **dev profile**（本轮手验用）：验**业务功能**（评论 / 问答 / @ / 举报 / 管理端六 tab / 块 7 五页）。
    原因：dev 与 a3 两个 profile 的 `app.auth.enabled=false`（**只有默认 profile 是 true**）
    ⇒ 在这两个 profile 上，「未登录会被 401」这类鉴权判据**永远验不出来**（一切匿名可达）。
  · **默认 profile**：验**鉴权**（未登录 / 越权）。见 §D —— 要重启后端切 profile，**不是**在 dev 上点。
  · ⇒ 一句话：**dev 全绿 ≠ 默认 profile 绿**。两份都要过。

⚠️ 本清单里凡是「台账里有行」的判据，都要求**实时日志页开着**（理由见 §〇-5）。
