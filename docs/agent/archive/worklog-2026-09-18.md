## 学到的方法论

### 1. 只读探索 → 方案 JSON → 确认 → 才写代码
探索成本 5–10K token，改错代码要 50–100K token 修。

### 2. 只输出 unified diff，禁止贴完整文件
585 行 Controller 改 3 行，diff 只输出 6 行。

### 3. 门禁拆两步，不串一起
- 反例：`echo "检查" && git add .`（检查拦不住写操作）
- 正例：先 `git add --dry-run` 看数字，确认后再 `git add .`

### 4. 一个 feature 一个会话，做完 /clear
新会话读 3 个文件（agent.md + README + pack），不依赖历史对话。

### 5. 悬空引用必须消除
文档说"见 XX 文件的 YY 节"，那个东西必须真实存在。

| 坑                                    | 教训                                           |

| Windows bat 脚本 `tree` 参数错        | 跨平台脚本坑多，Agent 有文件读取能力就别造轮子 |
| `.gitignore` 的 `**/node_modules/` 漏 | 多层目录要通配                                 |
| docx 被提交                           | 二进制文件不该进 Git                           |
| amend 前忘 `git add`                  | 每次 amend 前先 `git status`                   |
| `gh run list --commit <sha>` 假阴性   | 工具不能用时换 `--json` 全量比对               |
| Vue 版本凭记忆列清单漏了 2 处         | 修文档前先 `grep` 全文                         |
