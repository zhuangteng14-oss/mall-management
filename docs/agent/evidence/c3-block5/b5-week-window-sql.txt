      LOCAL_NOW  = (NOW() + INTERVAL 8 HOUR)
      WEEK_START = DATE_SUB(DATE(LOCAL_NOW), INTERVAL WEEKDAY(LOCAL_NOW) DAY)
      THIS_WEEK  = (c.created_at + INTERVAL 8 HOUR) >= WEEK_START

   全部用纯表达式 + 哨兵时刻验证边界。

--------------------------------------------------------------------------------
[1] 库时钟 / 本地墙钟 / 本周起点
--------------------------------------------------------------------------------
── SELECT NOW() AS UtcNow, @@system_time_zone AS SysTz, (NOW() + INTERVAL 8 HOUR) AS LocalNow,
          WEEKDAY(NOW() + INTERVAL 8 HOUR) AS LocalWeekday,
          DATE_SUB(DATE(NOW() + INTERVAL 8 HOUR), INTERVAL WEEKDAY(NOW() + INTERVAL 8 HOUR) DAY) AS WeekStartLocal ──
UtcNow              | SysTz | LocalNow            | LocalWeekday | WeekStartLocal
2026-10-11 15:17:05 | UTC   | 2026-10-11 23:17:05 | 6            | 2026-10-05
(1 行)

判读：库时钟 = UTC（@@system_time_zone 实证，不是假设）；
      本地墙钟 23:17:05（+8h 后）；
      WEEKDAY = 6 ⇒ 今天是**周日**；
      WeekStartLocal = 2026-10-05 ⇒ 本周一，DATE_SUB(..., INTERVAL 6 DAY) 从 10-11 退回 10-05 ✓。

--------------------------------------------------------------------------------
[2] DaysLeft（§1.3）
--------------------------------------------------------------------------------
── SELECT (7 - WEEKDAY(NOW() + INTERVAL 8 HOUR)) AS DaysLeft ──
DaysLeft
1
(1 行)

判读：**周日 = 1** —— 与计划「周一 = 7 … 周日 = 1」一致，且恒 ≥ 1 ✓。
      ⚠️ 手验陷阱成立：今天建的券，明天（周一）就掉出「本周」。

--------------------------------------------------------------------------------
[3] 本周一边界哨兵（UTC 时刻 → 本地对比）
--------------------------------------------------------------------------------
── SELECT TIMESTAMP('2026-10-04 16:00:00') AS UtcMondayLocalMidnight,
          ((TIMESTAMP('2026-10-04 16:00:00') + INTERVAL 8 HOUR) >= WeekStart) AS ShouldBe_IN ──
UtcMondayLocalMidnight | ShouldBe_IN
2026-10-04 16:00:00     | 1
(1 行)

── SELECT TIMESTAMP('2026-10-04 15:59:59') AS UtcJustBefore,
          ((TIMESTAMP('2026-10-04 15:59:59') + INTERVAL 8 HOUR) >= WeekStart) AS ShouldBe_OUT ──
UtcJustBefore       | ShouldBe_OUT
2026-10-04 15:59:59 | 0
(1 行)

判读：`2026-10-04 16:00:00 UTC` + 8h = `2026-10-05 00:00:00` 本地 = 本周一 00:00
      ⇒ **恰在边界上算「本周」**（>= 闭区间）✓
      前一秒 `15:59:59 UTC` + 8h = `2026-10-04 23:59:59` 本地（周日）
      ⇒ **排除** ✓
      ⇒ THIS_WEEK 的半开/闭边界与「自然周（周一起）· 本地 +08:00」的裁定完全对齐。

[5] EndDaysLeft 的 TIMESTAMPDIFF 取整方向（§1.4 每行的「X 天后过期」）
--------------------------------------------------------------------------------
── SELECT TIMESTAMPDIFF(DAY, NOW(), NOW() + INTERVAL 30 HOUR) AS EndDaysLeft_30h,
          TIMESTAMPDIFF(DAY, NOW(), NOW() + INTERVAL  5 HOUR) AS EndDaysLeft_5h,
          TIMESTAMPDIFF(DAY, NOW(), NOW() - INTERVAL  1 HOUR) AS EndDaysLeft_past ──
EndDaysLeft_30h | EndDaysLeft_5h | EndDaysLeft_past
1               | 0              | 0
(1 行)

判读：`TIMESTAMPDIFF(DAY, ...)` **向下取整**：
      还剩 30h ⇒ 1（「1 天后过期」）
      还剩  5h ⇒ 0（前端 `endLabel` 渲染成「今天过期」—— 计划里那条 `<= 0 ⇒ 今天过期` 命中）
      已过期   ⇒ 0（同上，但只在 `Bucket='expiring'` 行才渲染，见 §1.4 注）
      ⇒ 前端 `endLabel` 的 `n <= 0 → '今天过期'` 分支**确实可达**，不是死代码。
