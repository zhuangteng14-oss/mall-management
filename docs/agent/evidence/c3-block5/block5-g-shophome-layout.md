## 2 · 本店热销：竖直柱状图

### 2.1 形态

```
   10          8           6          5        ← 数值（骑在柱顶上方）
   ◯          ◯           ◯          ◯        ← 圆形商品图（直径 == 柱宽 ⇒ 读成「柱的圆头」）
  ┃          ┃           ┃          ┃
  ┃          ┃           ┃          ┃
 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    ← 0 基线（贯穿整行 1px --axis-line）
  1 耳机     2 充电器     3 键盘     4 鼠标      ← 名次 + 商品名
```

- **X 轴 = 商品、Y 轴 = 销量**（用户原话「本店热销这块要竖的那种」⇒ 竖直柱，**不是横条**）。
- 取 **5** 条（上一版是 3）。
- 整列是一个 `<router-link>` ⇒ **点柱子进对应商品**（用户的「可点」）。
- 一根柱都画不出来 ⇒ 占位，**不画一个空坐标轴**（空轴比一句话更假）。

### 2.2 取材依据（联网查的图表规范，逐条对上）

用户原话：「允许你去联网搜索学习人家的样式或布局」。
来源：[Refactoring UI 数据可视化参考](https://github.com/wondelai/skills/blob/HEAD/refactoring-ui/references/data-visualization.md#1) ·
[Anvil2 Chart Types](https://anvil.servicetitan.com/docs/web/data-visualization/chart-types) ·
[diagram-design/type-bar](https://github.com/cathrynlavery/diagram-design/blob/main/skills/diagram-design/references/type-bar.md#1) ·
[AddTwo Rule 22](https://www.addtwodigital.com/add-two-blog?offset=1628841600500)

| 规范原话 | 本笔落法 |
|---|---|
| 「Bars → value at the tip. **Columns → value on the cap**」 | 数值标在**柱顶上方**，柱内不写 |
| 「slight rounding on top only」`4px 4px 0 0`，基线方角 | `border-radius: var(--r1) var(--r1) 0 0` |
| 「Rounding the top of a bar **suggests the value is rounded**」 | ⇒ 圆角只给柱**顶**且只 4px；**圆的只有商品图**（圆的是图，不是数据） |
| 「Always start the value axis at zero」 | 轴走 0 基线，**所有柱同一个比例尺**（除以榜首，不是「在最小值和最大值之间插值」） |
| 「Limit to 5–8 bars」 | **取 5** |
| 「Order bars by value」 | 降序 |
| 「reserving a highlight color for a **hero** bar」 | 榜首那根走 `--brand`，其余 `--surface-3` |
| 「text should never wear the data color」 | 数值走 `--ink-2`，**不是**柱色 |
| 轴 / 标签走既有 token | 基线 `--axis-line`、名次 `--ink-3`、名 `--ink-2` |

## 3 · 占位清单（用户新规：数据不足 → 占位，不静默消失）

| 块 | 触发 | 占位文案 | 为什么这句不是造假 |
|---|---|---|---|
| 本店优惠券 | 未登录 | 「登录后可领取本店优惠券」+「去登录」 | 说的是**条件**，没声称本店有没有券 |
| 本店优惠券 | 已登录但 0 张 | 「本店暂时没有可领的优惠券」 | 后端真回了空列表 |
| 本店热销 | 无一条 `SoldQty > 0` | 「本店还没有销售记录」 | 同上 |
| 本店折扣 | `OriginalPrice > 0` 一条都没有 | 「本店暂时没有折扣商品」 | 同上（**今天就是这一支**：全库 43 行原价全是 `0.0`） |
| 猜你喜欢 | 取不到同类目别家货 | 「暂时没有可推荐的同类商品」 | 同上 |
| 头卡事实行 | 四项全空 | 「暂无店铺资料」 | 同上 |

三条边界（写死在 `phText` 那个统一出口里）：

- **载入中说「正在读取…」**，**不冒充「没有」** —— 这正是「占位 ≠ 造假」的分界；
- **就绪但空**才说那句占位；
- **出错时回空串**（那一块整行不渲染）：主块已经把错误 + 重试按钮放在手边了，
  每一块再喊一遍「没取到」是噪音。

⚠️ **唯一一处「不给占位」并登记理由**：**认证徽章**。`CertStatus` 为空串的含义是
「这个登录名没有申请记录」，而实测 15 条 `merchant_application.Username` 与 13 家店名的
**交集是空集** ⇒ 更像**两边键对不上**。写「未认证」= 可能的一句**假否定** ⇒ **不画，留人裁**。

### 4.1 自评时**扣下**的两条，现在有答案了

1. **柱状图会不会读成「卡里套卡」？** —— 不嵌套。柱与图是两个独立 mark，
   **没有「卡」这个容器**（没有边框、没有底、没有圆角包住它们），只有 `.col` 这一个可点区域。
   判：**不嵌套**。
2. **⚠️ 榜首柱用实心 `--brand`，会不会与「全页唯一实心块 = 关注按钮」打架？**
   —— 落码时**刻意没有预设结论**，按 `--brand` 落，**用截图判**。截图结果：
   - `--brand` = `#3b7966`，一枚**低饱和墨绿**，不是会喊的颜色；
   - 「关注」是右上角头卡里 `34px` 高的**描边**小按钮（未关注态才实心），
     与柱状图一上一下、隔着整屏；
   - ⇒ **不打架**。保留 `--brand` hero，并把 `tokens.css` 那条「唯一实心块」的注释
     **收窄为「头卡里唯一」**（柱是**数据标记**、无任何可点的暗示；那条纪律要管的是
     **控件**之间抢注意力，而图表规范本身也建议给 hero bar 一个高亮色）。
