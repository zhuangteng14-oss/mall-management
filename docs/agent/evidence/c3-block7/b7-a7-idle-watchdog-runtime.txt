判读
  1. 首帧立即写出（1 帧，316 字节），此后节拍 3000 ms 未到，看门狗在 ~2.5 s 时判定
     「连续 1500 ms 没有一次成功写出」⇒ 从 sse-idle-watchdog 线程主动断开。
  2. curl 正常退出（rc=0）——流是被服务端结束的，不是客户端超时。
  3. 生产默认值下（interval 1000 ms、idle 30000 ms）每秒都有成功写出 ⇒ 健康流**不会**
     被看门狗误杀；此前 50 s 长连接实测未断开，与本条一致。
  4. 判据口径：这里的"空闲"= **没有一次成功写出**（含心跳），不是"没有新事件"。
     这样半死连接（写阻塞）会被掐断，而安静的页面（没有新事件但心跳在写）保持在线。

补充：确定性单测 SseStreamWriterIdleTest（2 条，负向"写阻塞必断" + 正向"正常写不许断"）
      覆盖同一行为，不依赖真实时钟与网络。
