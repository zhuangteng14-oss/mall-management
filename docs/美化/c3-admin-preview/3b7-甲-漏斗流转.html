结构判据（本页不是设计稿，是拿来比构图的）
  • C1 相邻区块不同构：① 读数带（三组横排）→ ② 漏斗装置（单张 SVG）→ ③ 取消折叠（4/8 两栏）→ ④ 最近订单（单列行）。3 对相邻，逐对不是同一种布局；没有两块共用同一套直接子元素结构。
  • C2 不是卡片网格：全页 0 个等宽等高卡片。五态不以 5 张 KPI 卡出现，只以漏斗节点（累计数）与折叠面板（取消总账）出现。
  • C3 区块间距 > 内部间距：区块之间 28px（--gap-block），块内 12px（--gap-in）；读数带内 12px，折叠面板内 12px。
  • C4 一套网格与边距：主区 padding 32px、12 栏栅格、间距只有 12 / 28 两档；页宽沿用共用 .px，与另外几版草图同一把尺。
  • 大胆装置：横向段长 = log（平均耗时），竖柱高 = 累计单数，节点下 = 占创建比，段上 = 相邻转化率；取消是一条从主线剥出的虚线支线 —— 四种量共用一张装置，替代环形图。
  • 取消压力态（结构检查）：取消是独立支线 + 折叠面板，主线节点的位置与柱高只由「到达量」决定。取消 35/256 = 13.7% 时主线完整；取消 255/256 = 99.6% 时主线只是柱高变短、数字变小，布局不塌 —— 这是本版相对环形图的直接理由。
