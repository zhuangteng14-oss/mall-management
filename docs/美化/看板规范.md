# 可视化看板规范

> **可视化段 commit 1（2026-10-11）**。这份管的是「数据怎么画成图」—— 组件怎么分工、
> 颜色从哪来、三态怎么摆、以及几条**踩出来的**硬规矩。
> 它**不是设计稿**（设计稿在 `c3-admin-preview/`，色相来源见那里的丁版），是**落码时的口径**。

## 0. 一句话

一张看板 = 一排 `KpiCard` + 若干张图表卡；**颜色 / 字号 / 间距一律走 token，组件里一个 `#hex` 都不出现**。

## 1. 件在哪

| 文件 | 是什么 |
|---|---|
| `src/components/charts/echarts.js` | **唯一**的 `echarts.use(...)` 注册点（按需注册，见 §4） |
| `src/components/charts/chartTokens.js` | 读 CSS 变量 → option 片段（色板 / 轴 / tooltip / 图例 / 混色） |
| `src/components/charts/BaseChart.vue` | 底座：init / setOption / resize / 三态浮层 / dispose |
| `…/charts/{Line,Bar,Pie,Donut,Heatmap}Chart.vue` | 五个图，各自把数据摊成 option |
| `src/components/ui/KpiCard.vue` | 指标卡（标签 + 大数字 + 一行环比） |
| `src/components/ui/IconGlyph.vue` + `glyphs.js` | 字形图标 11 枚 |

**props 一律「传数据、不传样式」**：`categories` / `series` / `data` / `xLabels` / `yLabels`，
加少量行为开关（`horizontal` / `stacked` / `area` / `rose` / `labelTruncate` / `max`）。
**颜色不是 prop** —— 想换色请改 token，不要在调用处传色值。

## 2. 五条硬规矩（每条都踩过）

### 规矩 1 —— 颜色只从 CSS 变量**现读**，不硬编码

`chartTokens()` 是**函数**不是模块级常量，因为两套主题下这 16 个名字**同名不同值**
（浅色 `:root` 与 `html[data-theme="admin"]`）。模块级读一次就把「首次求值时的主题」冻住了：
暗色页若晚于浅色求值，就会拿到浅色的线 —— 在暗底上几乎看不见，**且不报错**。

两条容易漏的细节：

- `getComputedStyle(...).getPropertyValue('--x')` 返回**带前导空格**的原样串（`' #2f6fed'`）
  ⇒ 一律 `.trim()`。少了这步 ECharts 的颜色解析会**静默失败**、退化成它自带的默认色板 ——
  而 ECharts 默认色板恰好也是蓝橙系，肉眼不容易发觉。
- 主题在**页面加载时**由 `public/index.html` / `public/admin.html` 定死在 `<html>` 上，
  本仓**没有运行期切主题** ⇒ 「建图时现读」够用。真要加切主题，得让 option 也依赖主题信号
  （把这一层改成 reactive），**别只改 `chartTokens`**。

色板只做**面积填充**（线 / 柱 / 扇区）；**图上文字一律走 `--axis-label`** ——
图形对象的线是 **3.2:1**，正文的线是 **4.5:1**，两个档次不许混用。
（浅色那 10 个色值不是照搬丁版：丁版是对暗底 `#101828` 调的，搬白底上有 **6 条**不到 3:1
（`#ff6a00` 2.87 / `#22c55e` 2.28 / `#f59e0b` 2.15 / `#06b6d4` 2.43 / `#84cc16` 1.98 / `#38bdf8` 2.14）
⇒ 保色相、OKLCH 降 L 到白底 ≥3.2:1，另外 4 条原色过线照搬。
推导脚本 `scripts/probes/derive-light-palette.mjs`，跑一次打一张逐色对照表。）

### 规矩 2 —— 三态是**不透明浮层**，不是把 canvas 换掉

`BaseChart` 的 canvas 容器**始终挂载**；加载 / 空 / 错误三态是**盖在上面的绝对定位浮层**。

- 为什么不 `v-if` 掉 canvas：拆了再建，`ResizeObserver` 要重挂、尺寸要重算，
  数据回来的一瞬会闪一下白。留着 canvas、只盖一层，切换是「一帧盖上去」。
- ⚠️ **浮层必须不透明**（`.bc-state` 给 `background: var(--surface)`）。
  半透明的话底下的旧图 / 网格线会透出来当背景纹 —— 看起来像渲染坏了。
- 三态**互斥**，优先级 `error > loading > empty`（`state` computed 就这一行）。
- 错误态带重试按钮，抛出 `retry` 事件由调用方接。

### 规矩 3 —— 数字格式化归**调用方**，组件不管

`KpiCard.value` 收的是**已经格式化好的字符串**（`'1,284'` / `'96.4'`）。
「千分位 / 保留几位 / 要不要缩写成万」是三端各不相同的显示口径，是调用方的决定。
组件只管排版：单位跟在数字后面小一号、数字走 `--font-mono` + `tabular-nums`。

同理 `delta` 只收**带符号的百分数**（`8.2` / `-0.4` / `0`）；**涨了是好事还是坏事**由
`inverse` 决定 —— 退款率、异常数、锁等待这类指标涨了要标红，但箭头方向仍按数值符号走。
（配色与方向**分两个变量**算，别混成一个。）

### 规矩 4 —— 热力图的 `visualMap.max` **必须显式给，且由数据算**

这条是本笔实测炸出来的，两种失效都不报错（或报得看不懂）：

1. **以「键在、值为 `undefined`」的形式传下去**（`max: undefined`）⇒ ECharts 会把它算进
   `dataExtent`（`VisualMapModel.resetExtent` = `asc([min, max])`，**它不从数据推算**）
   ⇒ 上界成 `undefined` ⇒ 画手柄横条时 `addColorStop('undefined')` 抛 `SyntaxError`，
   **整块画布停在半帧**。报错在 `zrender/lib/canvas/helper.js`，跟热力图看不出关系。
2. **压根不给** ⇒ `visualMap` 的默认 `max` 是 **200**。真数据全在 60 上下时，
   整张图的格子全挤在色阶最底部深浅难分 —— 图上「有东西」，但读不出梯度。

⇒ 所以 `HeatmapChart` 里有个 `resolvedMax`：调用方给了就用，没给就**按数据第 3 维取最大**，
再向上取到整数档（10 / 20 / 50 / …）；空数据给 1。**永远给一个数，永远不是 `undefined`。**

### 规矩 5 —— 图标用**字形**，不引 icon 库

11 枚字形（`◧▤▦◍◎⚡◔↻≣⚿⚙`）直接取自丁稿侧栏，`glyphs.js` 一张表。理由：多一个依赖只为
11 个符号不划算，且这套字形本身就是稿子视觉的一部分。**未知名字不静默吞掉** ——
渲染回落字符 `·` 并在非生产环境 `console.warn`（便于探针断言「没有一枚落到 `·`」）。

## 3. 房规（沿用 `tokens.css` 既有口径）

- 数字列一律 `font-variant-numeric: tabular-nums` —— 否则多个 KPI 并排时数字宽度不同，
  单位字会左右错位。
- **不写 y 轴 `name`**：ECharts 把轴名摆在轴顶端，多轴时挤成一团。
  单位并进轴标签 `formatter`，轴名交给卡头那行字。
- 图表内文字 **11px**（`chartTokens.TEXT_SIZE`）—— 比正文最小档 `--fs-xs`(12px) 再低一档，
  是刻意的：图表文字不该与正文同档。
- 饼 / 环 / 热力的格子 `itemStyle.borderColor` 取**当前主题底色**，不写死白 ——
  写死白在暗色下会变成一圈亮框。

## 4. ECharts 按需注册

只在 `src/components/charts/echarts.js` 一处 `echarts.use([...])`，import 走
`echarts/core` + `echarts/charts` + `echarts/components` + `echarts/renderers`。
当前注册：`LineChart` / `BarChart` / `PieChart` / `HeatmapChart` + `Grid` / `Tooltip` /
`Legend` / `VisualMap` / `AxisPointer` 五件组件 + `CanvasRenderer`。

⚠️ **加新图型第一件事是回这里补注册** —— 漏了不会编译报错，只在运行时报
「Component xxx not exists」，而图是**空的**。

**包体账（commit 1 结不出来）**：本 commit 只是把 `echarts` 加进 `dependencies` 并写好组件，
**没有任何视图 import 它们** ⇒ 打包产物里查不到 echarts
（`grep -l zrender dist/js/*.js` 为空），JS 产物与 commit 0b 一致。
真实的按需注册收益要等 commit 2 的看板页把组件接上才量得到。

## 5. 新增一张图要动哪几处

1. `echarts.js` 补注册（图表类 + 可能缺的组件类）
2. 新组件 `.vue`：**照抄 `BaseChart` 那组三态 props**（`loading` / `error` / `emptyText` / `retry`），
   别自己再造一套
3. `chartTokens.js` 若确实需要新的 option 片段（先问：能不能用现成的）
4. 新 token —— **先问能不能用 `--c1`-`--c10`**；不加色就去加，色板会越滚越散
5. 探针补断言

## 6. 复核

`node scripts/probes/probe-vis-charts.mjs`（要求 dev server 在 8080）

判据是**画布上的不透明像素数**，不是「有 `<canvas>` 标签」—— 空白画布（只 `init` 没 `setOption`）
也有 `<canvas>`，只有数像素才分得出「画了」和「没画」。它同时断：

- 两套主题**各跑一遍**，并断「两套的 `--grid-line` 确实不同」（token 按主题换值真的生效了）
- 末两条断「两套都**零 JS 错误**」—— 热力图那个 `addColorStop` 就是靠这条抓出来的
